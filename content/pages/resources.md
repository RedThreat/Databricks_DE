## Training courses

The exam pages recommend these Databricks Academy courses ([Databricks Academy](https://customer-academy.databricks.com/); [course list](https://www.databricks.com/learn/training/data-engineering-courses)):

- **Associate**: Data Ingestion with Lakeflow Connect; Deploy Workloads with Lakeflow Jobs; Build Data Pipelines with Lakeflow Spark Declarative Pipelines; DevOps Essentials for Data Engineering.
- **Professional**: Databricks Streaming and Lakeflow Declarative Pipelines; Databricks Data Privacy; Databricks Performance Optimization; Automated Deployment with Databricks Asset Bundles.

Course titles may still use older product names.

## About this site

- Topic pages are written from the official exam guides and the Databricks documentation, in plain language, and cover both exams.
- Practice questions are original or adapted from practice exams; none comes from a real exam.
- Progress (ticked objectives, plan days, history, missed questions) is stored only in your browser.
- To edit content, change the Markdown and YAML files in the repository's `content/` folder and run `python3 build.py` (see the README).
